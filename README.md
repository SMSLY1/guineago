# 🇬🇳 GuineaGo

### Découvrir la Guinée autrement 🌍

GuineaGo est une application mobile développée avec Flutter et Dart.
Elle a pour objectif de faire découvrir les richesses touristiques de la
Guinée aux Guinéens et au monde.

L'application permet de découvrir des destinations touristiques, de consulter
leurs informations et d'enregistrer ses destinations favorites.

---

## 🎯 Objectifs du projet

- Promouvoir le tourisme en Guinée.
- Faciliter la découverte des destinations touristiques.
- Mettre en valeur le patrimoine naturel, culturel et historique.
- Proposer une expérience mobile simple et accessible.

---

## ✨ Fonctionnalités

### 🔐 Authentification
- Connexion avec une adresse e-mail et un mot de passe.
- Connexion avec Google.
- Réinitialisation du mot de passe.
- Déconnexion.

### 🗺️ Destinations touristiques
- Consultation des destinations.
- Recherche de destinations.
- Filtrage par catégorie.
- Consultation des détails d'une destination.
- Enregistrement des destinations favorites.

### ❤️ Favoris
- Ajout de destinations aux favoris.
- Consultation des destinations enregistrées.

### 👤 Profil utilisateur
- Consultation du profil.
- Modification des informations du profil.
- Gestion du compte utilisateur.

### 👥 Guides touristiques
- Consultation des informations disponibles sur les guides.

> Certaines fonctionnalités sont encore en cours de développement ou
> d'amélioration.

## 🚀 Installation du projet

### Prérequis

- Flutter installé.
- Dart installé.
- Android Studio ou Visual Studio Code.
- Un appareil Android ou un émulateur.

### Cloner le dépôt

```bash
git clone https://github.com/SMSLY1/guineago.git
```

### Accéder au projet

```bash
cd guineago
```

### Installer les dépendances

```bash
flutter pub get
```

### Lancer l'application

```bash
flutter run
```
